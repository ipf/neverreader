# Code of Conduct

This repository is licensed under the Mozilla Public License 2.0, and it was
imported from Pocket, a Mozilla company. The community guidelines it was
published under are therefore still the inherited ones:

[Mozilla Community Participation Guidelines](https://www.mozilla.org/about/governance/policies/participation/)

Reporting a violation, and how reports are handled, is described on their
[reporting page](https://www.mozilla.org/about/governance/policies/participation/reporting/).

The one thing to know here: there is no team to escalate to. This fork is
maintained separately, and reports should go to the maintainers of this
repository rather than to Mozilla.
